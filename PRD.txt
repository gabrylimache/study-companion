PRODUCT REQUIREMENTS DOCUMENT (PRD)

Pollock - Study Companion
Project Overview

Create a production-ready portfolio project called Pollock - Study Companion.

Pollock is an interactive study companion that lives in the browser.

The application uses webcam-based hand gesture recognition to trigger reactions from a custom animated companion.

The companion already exists and MUST be reused.

Do not create a new character system.

Do not create a 3D avatar.

Do not replace the companion framework.

The companion is exported from Bible Strong Avatar Lab and provided as:

avatar.avatar.json


using:

import { createAvatar } from "@bible-strong/avatar-react"
import "@bible-strong/avatar-react/styles.css"
import definition from "./avatar.avatar.json"

const Avatar = createAvatar(definition)


The application must be built around this system.

Core Interaction System

The webcam must be used locally through browser APIs.

Use:

MediaPipe Hand Landmarker


Do not train custom machine learning models.

Do not use external AI services.

Do not use OpenAI APIs.

Do not use cloud inference.

Gesture recognition must be performed using hand landmarks and geometric rules.

Official Gesture Mapping

Cooldown System

Avoid animation spam.

Requirements:

Gesture detected
→ play animation

Ignore new gesture triggers for 2 seconds

Allow re-trigger afterwards

Idle System

When no gesture is detected:

idle behavior

drowsy
